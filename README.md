# HackaMeter
HackaMeter is a HackaTime extension which mainly focuses on extra stats, more info, and optional journalling. This is going to be THE custom HackaTime dashboard.



## nerd stuff
HackaMeter is truly not a HackaTime extension, but actually is simply a custom dashboard using HackaTime's api to gather information. Information gathering is key to a good dashboard. It uses sveltekit, and nodejs as it's tech stack. A little bit weird one may say, and you'd be right! For the backend, there are two servers, one in Canada, the other one in Finland. The one in Finland is from https://hackclub.app, a great place to host your own servers!


## how to run it locally
No docker required
(partially cuz idk how to use it lol)
### prerequisites
 node.js https://nodejs.org/en/download

### step 1: clone it
```bash
git clone https://github.com/BlxCode/Hackameter.git
```

### step 2: enter the ~~matrix~~ folder
``` bash
cd Hackameter
```

### step 3: install dependancies
``` bash
npm install
```

### step 4: run the classic command:
``` bash
npm run dev
```
### step 5: open your browser and go to
